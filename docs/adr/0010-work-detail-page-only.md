# 0010: 作品詳細を通常のページ表示に統一する

- ステータス: 採用
- 日付: 2026-09-17

## 決定

作品詳細は `/works/:slug` への通常のページ遷移で表示する。ドロワー、履歴の同期、fragment ルート、動的挿入用のハイドレーションを廃止する。ADR 0004 と 0005 を置き換える。

768px 未満ではカルーセルと説明を縦に並べる。768px 以上では左にカルーセル、右にタイトル・カテゴリ・本文を縦に並べる。1024px 以上ではカルーセルを画像の縦並びに切り替え、説明と上揃えにする。既存のカルーセルと CSS Modules を維持し、レイアウトは CSS Grid で実装する。

## 根拠

遷移元による表示の違いをなくし、タブレットと PC では画像と説明を同時に読める構成にする。通常のリンクと HonoX の標準ハイドレーションで実現できるため、独自のルーティング処理は不要になる。
