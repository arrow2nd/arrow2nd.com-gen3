## 概要

3年ぶりにリニューアルしたポートフォリオサイト。

## 特徴

作品ページはトップページからだとドロワーで、URLに直接アクセスするとページになります。

また、サイト内の色は1つのテーマカラーからバリエーションを生成しているので、気分で色合いが変わるかもです。

## ひとこと

古くなってきたな〜と思ったので、デザインも一新して作りなおしました。

## 使用技術

Node.js / HonoX / CSS Modules / Cloudflare Workers
