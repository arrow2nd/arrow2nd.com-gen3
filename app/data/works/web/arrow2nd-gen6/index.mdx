## 概要

3年ぶりにリニューアルしたポートフォリオサイト。

## 特徴

ぽこぽこ動きます。

## ひとこと

最近つくっている AI アシスタントの [Ruru](/works/ruru-ai) をどこかに登場させたいな、と思っていたので各作品ページにコメントを書いてもらいました。

<br/>

サイト内の色は1つのテーマカラーからバリエーションを生成しています。

デフォルトは茶色ですが、変更権限は Ruru が持っているので気分で色が変わるかも。


## 使用技術

Node.js / HonoX / CSS Modules / Cloudflare Workers

2026年6月
