## 概要

インターネットのかたすみに画像をおけるサービス。

## ひとこと

写真を撮ることがすきなんですが、「TwitterやInstagramに上げるのはちょっとデカいインターネットすぎて気が引けるぜ〜」と思っていたのでつくりました。

URLをシェアしてようやく辿りつける、くらいのかたすみな場所になっています。

## 使用技術

Node.js / TanStack Start / Tailwind CSS / Better Auth / Drizzle ORM / Turborepo / Cloudflare Workers・Queues・D1・R2 / OpenAI API

2025年12月
