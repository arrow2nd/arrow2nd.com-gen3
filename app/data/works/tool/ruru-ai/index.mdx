## 概要

AI ホームアシスタントのようなもの。

## できること

- Discord の会話に参加する
- Android のアシスタントアプリとして振る舞う
- 家電やカレンダー、Spotifyなどの操作
- 定期的に情報を確認し、記事の推薦や通知、必要な行動を判断する
- MCP で外部ツールを使い、Codex などの AI エージェントと対話する

## ひとこと

Vibe Coding やってみるか……でつくりはじめたアシスタント。

エグいスクラップ&ビルドを繰り返しながら今の姿になりました。

このページの紹介文は Ruru が監修してます。

## 使用技術

Python / Pydantic AI / FastAPI / SQLite / Kotlin / Jetpack Compose / OpenRouter / Docker
